10. Library reactions (p, d, t, ³He, α): reaction probability, yields and secondary spectra (how to use)

  1. Choose p, d, t, ³He or α as the beam particle. The panel Nuclear reaction data (ENDF-6) appears on the left and uses the library of that projectile (TENDL-p, -d, -t, -h or -a). Everything below (plots, tables, secondary spectra) works identically for the five projectiles; the symbol of the projectile replaces α in the labels, e.g. (p,n) or (d,α), and “per incident p”.
  2. Choose the library folder: the TENDL2025 folder, which holds the sub-folders TENDL-a, TENDL-p, TENDL-d, TENDL-t and TENDL-h (the sub-folders are searched), or a single one of them. The files of the sublibrary of the projectile selected are used (prefix a-, p-, d-, t-, h- for α, p, d, t, ³He); changing the beam particle switches library without choosing the folder again. One file per isotope, named a-Ar040.tendl: element symbol + three-digit mass number; files of isomers such as …m are ignored). Only the names of the files are indexed; a file is opened only if its isotope is in the target (natural or edited abundances), when you press Run simulation or Re-read target isotopes. Isotopes without a file keep the built-in model cross section. Only the files of the target isotopes are ever opened; the browser’s folder dialog just lists the file names. The files follow the materials: when you edit a layer (other element or isotopes) or change the beam particle, the files of the new isotopes are read automatically; no need to choose anything again. Chromium-based browsers remember the folder. Inside the Claude viewer the folder is chosen through the file dialog.
  3. Saving the spectra. Every secondary-particle plot has its own Save this plot buttons (PNG, SVG, ASCII, CSV, ROOT file), and above the first plot Save all spectra stores all of them as shown (hidden angles, log axis and zoom included): PNG and SVG as a zip with one file per plot, ASCII and CSV as one file with a block per plot, ROOT as one file with all histograms (names prefixed p1_, p2_ … by plot).
  4. Non-elastic cross section for the transport (tick box, on by default): the removal of the projectiles uses MT 3 of the library instead of the model.
  5. Run, then open the tab Reactions (ENDF). Controls: Reaction channels (menu with tick boxes, one or several; All reaction channels is the sum of the non-overlapping channels), Plot (reaction probability dP/dE or cross section σ(E)), Layer, Energy unit, Bins, and Secondary energies from (two-body kinematics, default, or the lab double-differential data as filed).
  6. Read the results, from top to bottom: (a) the reaction-probability plot (one curve per layer, or per channel when several are ticked); (b) one plot per layer and secondary particle (n, p, d, t, ³He, α, photons and the recoil nuclei, all residual nuclei of the selected channels summed) with the energy distribution at the laboratory angles 0°, 5°, 10°, 30°, 60°, 120°, 160° (per primary, per MeV and per sr) and the distribution integrated over all angles, shown divided by 4π so that it is also per primary, per MeV and per sr (the angle-averaged value: equal to the angle curves for isotropic emission; multiply by 4π to get dN/dE; the saved CSV/ASCII/ROOT files contain what is plotted). Every one of these plots can be zoomed (drag a box, double-click resets), has its own linear/logarithmic Y axis, and angles are hidden or shown by clicking the legend; (c) the table with the reaction probability and the yields of n, p, d, t, ³He, α and photons per incident α, per layer, channel and isotope, plus the residual nuclei and a consistency line.

The line under each secondary plot says which data were used: the kinematics mode and the kind of angular data found in the file (Legendre, Kalbach-Mann with a from the file or from systematics, two-body discrete level, phase space, isotropic).
