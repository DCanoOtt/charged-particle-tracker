6. Simulation settings

  • Primary particles (up to 5,000,000; every primary keeps a few numbers in memory, so very large runs with many layers are refused), seed (same seed = same result). Cancel stops a run and keeps the results of the primaries already simulated.
  • More options: Tracks drawn (number of full tracks kept for the Tracks plot), Depth bins and Depth max of the depth histograms, and Stored track points: the memory kept for the radial/lateral analysis (millions of points, about 16 bytes each). If a run has more primaries than can be stored, the radial plots use the first stored tracks (unbiased, fewer samples) and say so.
  • Setup (left, bottom): Save setup to file downloads the whole setup (layers, beam, physics, simulation, your saved materials) as a .setup.json file; Load setup from file… restores it. The JSON can also be copied and pasted. Settings and saved materials are also remembered in this browser.
