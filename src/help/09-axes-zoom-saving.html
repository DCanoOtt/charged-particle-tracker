9. Axes, zoom and saving

  • Every plot has X/Y minimum and maximum (blank = automatic), linear or logarithmic X and Y scales, and editable title and axis labels; Reset axes & labels clears them. Histogram plots also have Bins and a Y-axis choice: fraction of primaries per bin, counts per bin or probability density. Click a legend entry to hide a curve.
  • Zoom: drag a rectangle on the plot (a thin band zooms one axis only), double-click to return. On histograms, zooming re-bins the visible range for more detail; touch screens use the buttons. Hover to read values.
  • Save plot: PNG (1200/1800/3000 px), PDF (image on a page), SVG (vector), ASCII (.txt with headers and columns), CSV, a binary ROOT file (one TH1D per series; inside the Claude viewer it comes in a zip), or a ROOT macro (a C++ macro that fills TH1D/TGraph objects and writes the .root file; remove the extra “.txt” from the file name, rename to .C and run root -l -b -q name.C). You are asked to confirm each save. “Copy CSV” puts the data on the clipboard.
